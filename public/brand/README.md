# Brand artwork

The files in this folder are **placeholders**. Replace each with the file of the same name from the approved
`Earldeign-Investments-Logo-Masters/svg/` package (Brand Manual v1.2, section 9). Do not trace, retype or edit the artwork.

| File | Used in |
|---|---|
| earldeign-compact-lockup-dark.svg | Left navigation (Deep Ink), 260 px wide |
| earldeign-compact-lockup-light.svg | Sign-in and account pages (Warm Off-white), 300 px wide |
| earldeign-full-lockup-light.svg | Reserved for document covers |
| earldeign-monogram-dark.svg | Favicon source (also copy to src/app/icon.svg) |

PDF documents use the PNG masters: add `earldeign-compact-lockup-light@2x.png` to this folder and it is picked up automatically.
